# Python Calculator

A small command-line calculator built with Python's standard library.

## Requirements

- Python 3.8 or newer

No third-party packages are required.

## Setup

Clone this repository and change into its directory:

```powershell
git clone https://github.com/Kishoore1905/python-calculator.git
cd python-calculator
```

## Usage

Run the calculator:

```powershell
python calculator.py
```

Choose `+`, `-`, `*`, or `/`, then enter two numbers. Enter `q` at the
operation prompt to quit. Invalid numbers and operations are reported, and
division by zero is prevented.

## Tests

Run the unit tests with:

```powershell
python -m unittest
```
